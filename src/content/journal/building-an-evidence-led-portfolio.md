# Building a portfolio around evidence

This is an AI-assisted editorial note about the portfolio project, not a completed security lab or a claim of independent technical work.

## What the site needs to communicate

Cybersecurity is the main direction. Networking, operating systems and programming explain the surrounding technical interests. A reviewer should be able to distinguish study, training, a public implementation and experience in a workplace.

## Decisions in this version

- Keep Professional Certifications separate from Training.
- Describe exams as passed according to the owner, without inventing issue dates or verification links.
- Link the CCNA study app only after reviewing its actual source.
- Store content in JSON and technical explanations in Markdown.
- Use hash navigation and static assets for GitHub Pages.
- Add a CV download only after the correct file is supplied and reviewed.

## Next evidence to collect

A reviewed CV, issuer evidence for the exams, IT Gate dates and scope, and a sanitized project artifact with an explanation of my specific contribution.

## Weekly review

Ask: What did I try? What did I observe? What failed? How did I check the fix? What can I explain without AI? Keep the full learning record, then feature only the clearest work.
