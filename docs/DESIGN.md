# Design direction

An engineering editorial: ink-dark backgrounds, mint-cyan emphasis, restrained violet detail and strong Space Grotesk typography. Inter provides a clear body-text rhythm. The layout uses generous spacing and fine structural lines rather than fake terminal output or random skill percentages.

The hero connects security, networking, systems and development through a lightweight SVG diagram. Selecting a node changes the explanation and points to its technical capability. A reviewed portrait gives the technical identity a human anchor. Conceptual project card illustrations are clearly distinguished from evidence in the reports.

Interactions include keyboard-accessible node selection, category filtering, an expandable archive, training/evidence disclosures, native Markdown dialogs, actual report downloads, copy email and phone navigation. Hash URLs allow report/journal deep links and refresh on a static host. Native dialogs contain focus and restore it to their opener.

The normal pointer stays visible. Native scrolling is preserved; there is no scroll hijacking. OS reduced motion removes animation and smooth scrolling, and a persistent manual motion control offers the same option. Touch layouts retain the same content and controls. Fonts and portrait are served from the same project path.

Content accuracy is part of the design: course completion is not presented as an issuer certification, source inspection is not presented as a completed lab, a missing CV does not produce a fake download, and AI assistance is stated in the relevant project report.
